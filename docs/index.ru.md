# GpsTracker — трекинг GPS в osysHome

Модуль `GpsTracker` нужен, чтобы получать геолокацию с телефонов/трекеров и превращать её в данные, которые osysHome может использовать в автоматизациях, на Dashboard и в интерфейсе модуля.

## Что делает модуль
- Принимает входящие координаты по двум основным протоколам: **uLogger** и **OwnTracks**.
- Хранит:
  - устройства (`GpsDevice`)
  - геозоны/«дом» (`GpsLocation`)
  - историю точек (`GpsPosition`)
- При каждом обновлении вычисляет:
  - находится ли устройство рядом с зоной «дом»
  - попадает ли точка в одну из геозон (и какая именно)
- Если устройство привязано к объекту osysHome (`linked_object`), модуль обновляет свойства объекта.

## Быстрый старт (для новичка)
1. В osysHome создайте объект для каждого пользователя/трекера (например, `JohnPhone`).
2. Добавьте на этот объект свойства (точные имена см. в разделе про привязку ниже).
3. Откройте `Admin -> GpsTracker`:
   - создайте **Device** и укажите **Linked object**
   - создайте **Location**:
     - одну запись с флагом **Is home** (это будет «дом»)
     - при желании — дополнительные геозоны (работают как “location”)
4. Подключите ваше приложение:
   - либо отправляйте координаты через **uLogger** на `POST /GpsTracker/client/index.php`
   - либо через **OwnTracks** на `POST /GpsTracker/owntracks`
5. Отправьте 1 тестовое сообщение и проверьте:
   - список устройств и карту
   - вкладку **Log** (история точек)

## Что можно делать с данными
- В автоматизациях определять события вроде “человек дома”, “человек в зоне работы”, “устройство заряжается”.
- Отображать на Dashboard координаты/зоны/статусы.
- Строить маршрут по истории точек (на карте в админке модуля).
