# Карта GpsTracker (админка)

Вкладка **Map** в `Admin -> GpsTracker` — интерактивная карта устройств, треков и геозон.

Полноэкранная страница `/page/GpsTracker` — только просмотр (без редактирования геозон и точек трека).

## Панель управления

Справа на карте:
- **Refresh** — перезагрузить устройства, локации и лог за выбранный период
- **+** — режим добавления геозоны (только на вкладке Map в админке)
- кнопка с иконкой маршрута — режим редактирования точек трека
- период: Today / Last 24 hours / Yesterday / Week / Custom
- список треков с Show all / Hide all

При смене видимых треков карта автоматически подстраивает масштаб (`fitBounds`).

Цвета треков берутся из свойства `color` связанного объекта; если цвет не задан — назначается стабильный цвет из палитры по `device.id`.

## Геозоны на карте (только вкладка Map)

1. Нажмите **+** и кликните по карте — создаётся черновик зоны (радиус по умолчанию 100 м).
2. Или кликните по существующему кругу.
3. Редактирование мышью:
   - красная точка в центре — перемещение зоны
   - маркер на краю — изменение радиуса
4. Рядом с кругом открывается карточка: название, Is home, Save / Delete / Cancel.

Данные сохраняются через REST:
- `POST /api/GpsTracker/location`
- `DELETE /api/GpsTracker/location/<id>`

На вкладке **Location** зоны по-прежнему можно править таблицей и модалкой.

## Редактирование точек трека (только вкладка Map)

1. Включите кнопку редактирования точек (рядом с **+**).
2. На видимых треках появятся точки.
3. Клик по точке — выбор; карточку можно использовать для удаления.
4. Перетаскивание выбранной точки — смена координат (сразу сохраняется).

API:
- `PUT /api/GpsTracker/position/<id>` — `{ "lat", "lon" }`
- `DELETE /api/GpsTracker/position/<id>`

Если видимых точек больше 500, режим не включается: сузьте период или спрячьте лишние треки.

## Подтверждение удаления

Удаление устройств, локаций и точек (на карте и во вкладках-таблицах) идёт через модальное окно подтверждения osysHome (`confirm` / `showConfirm`), а не через системный диалог браузера.
