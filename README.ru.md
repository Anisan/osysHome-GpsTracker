# GpsTracker - Модуль GPS отслеживания

![GpsTracker Icon](static/GpsTracker.png)

Система GPS отслеживания для приема и управления данными GPS местоположения с мобильных устройств и трекеров.

## Описание

Модуль `GpsTracker` предоставляет возможности GPS отслеживания для платформы osysHome. Он поддерживает протокол uLogger и предоставляет API endpoints для приема GPS координат с мобильных устройств.

## Основные возможности

- ✅ **GPS отслеживание**: Прием GPS координат с устройств
- ✅ **Поддержка uLogger**: Совместимость с протоколом uLogger
- ✅ **Управление устройствами**: Управление несколькими GPS устройствами
- ✅ **История местоположений**: Хранение истории местоположений
- ✅ **Расчет расстояния**: Расчет расстояния от домашнего местоположения
- ✅ **API endpoints**: RESTful API для GPS данных

## Панель администратора

Модуль предоставляет административный интерфейс для:
- Просмотра GPS устройств
- Просмотра истории местоположений
- Управления устройствами

## API

Модуль предоставляет API endpoints:
- **POST /client/index.php**: Endpoint, совместимый с uLogger
- **GET /api/GpsTracker/...**: RESTful API endpoints

## Поддерживаемые протоколы

- **uLogger**: Стандартный протокол uLogger для приложений GPS отслеживания

## Использование

### Прием GPS данных

1. Настройте приложение GPS отслеживания (например, uLogger)
2. Установите URL endpoint: `http://your-server/GpsTracker/client/index.php`
3. Аутентифицируйтесь с именем пользователя
4. GPS данные принимаются автоматически

## Технические детали

- **Протокол**: HTTP POST, совместимый с uLogger
- **Хранилище данных**: Хранение местоположений в базе данных
- **Расчет расстояния**: Формула Haversine для расстояния
- **Обнаружение дома**: Автоматическое обнаружение домашнего местоположения
