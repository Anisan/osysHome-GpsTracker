# Troubleshooting (частые проблемы)

## Не обновляются свойства объекта osysHome
Чаще всего причина в том, что:
- вы не создали свойства с точными именами на объекте (см. `using-in-osyshome.ru.md`)
- или используете другое имя объекта в `Linked object`

Важно: `GpsTracker` обновляет свойства через `updatePropertyThread(...)`, поэтому свойства должны существовать заранее.

## Запросы возвращают `401 Unauthorized`
Обычно это означает проблему с API key:
- ключ не передан
- ключ передан в неверном параметре/заголовке
- ключ не существует или изменился

Проверьте:
- что передаёте `?apikey=...` или `X-API-Key: ...`
- что ключ сохранён у нужного пользователя в `Admin -> Users`

## `home` всегда `0`
В `GpsTracker` не задана зона “дом”:
- в `Locations` есть геозоны, но ни одна не имеет `Is home = true`

Добавьте/поставьте флаг `is_home` у нужной зоны.

## `location`/`address` “не те”
Модуль берёт первую подходящую геозону:
- в коде нет явного приоритета `ORDER BY`
- при пересечении зон может срабатывать “не та”, просто потому что она оказалась первой

Решение:
- уменьшайте пересечение зон
- или подбирайте радиусы так, чтобы пересечения не было

## OwnTracks “друзья” пустые
Сервер отдаёт friends только для `GpsDevice`, у которых задан `linked_object`.
Если у других устройств `Linked object` пустой — ответа по friends не будет.
