# Определение адреса по координатам (Reverse Geocoding)

`GpsTracker` может определять читаемый адрес по координатам и сохранять его в GPS-лог (`gps_positions.address`).

## Настройки

Определение адреса настраивается в админке модуля:

- `Address provider` - выбор провайдера reverse-geocoding.

## Режимы провайдеров

- `Disabled`
  - Определение адреса отключено.
  - Внешний/клиентский адрес игнорируется.
  - Адрес не отправляется в связанный объект Users.

- `OpenStreetMap (Nominatim)` - без API key.
- `BigDataCloud` - без API key.
- `maps.co` - API key опционален (`mapsco_api_key`).
- `Google Geocoding API` - нужен `google_api_key`.
- `Yandex Geocoder` - нужен `yandex_api_key`.
- `LocationIQ` - нужен `locationiq_api_key`.

Если выбран провайдер с обязательным ключом, но ключ пустой, модуль безопасно пропускает определение адреса (без падения).

## Приоритеты определения адреса

При получении новых координат:

1. Если во входных данных уже передан `address`, модуль использует его без изменений.
2. Иначе сначала проверяются геозоны (`GpsLocation`).
3. Если точка попадает в геозону, адресом становится название геозоны.
4. Если геозона не найдена, используется выбранный провайдер reverse-geocoding (если не `Disabled`).

## Правила отправки в Users

- Если `address` явно передан во входном payload, он всегда отправляется в `.address` связанного объекта Users (даже при `Disabled`).
- Если `address` во входном payload нет, отправка в `.address` выполняется только когда провайдер не `Disabled`.

## Поведение формы настроек

В форме настроек поле API key показывается только для выбранного провайдера, которому нужен ключ.
